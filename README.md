# 🏨 Hotel Management System

A Java-based Hotel Management System designed to manage hotel operations through a graphical user interface. The project includes modules for guest management, room management, booking operations, login, and reporting.

## 📌 Project Overview

The Hotel Management System is a desktop application developed using Java. It aims to simplify basic hotel management tasks and organize hotel-related information in one application.

## ✨ Features

- **Login System** – User login interface.
- **Guest Management** – Manage guest information.
- **Room Management** – Handle room-related information.
- **Booking Management** – Manage hotel bookings.
- **Report Management** – View hotel management reports.
- **Data Management** – Store and manage application data.

## 🛠️ Technologies Used

- Java
- Java Swing (GUI)
- IntelliJ IDEA
- File Handling

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA or another Java IDE

### Installation

1. Clone the repository:

```bash
git clone https://github.com/utshodeb007/hotel-management-system.git
```

2. Open the project in IntelliJ IDEA.

3. Make sure the JDK is configured.

4. Open `src/Main.java`.

5. Run the `Main` class to start the application.
